# Александр Водопьянов — «Между строк»

Vue 3 + Vite + TypeScript + GSAP + Three.js. В архиве исходники, фотографии и модель микрофона. Привязка к хостингу не требуется.

## Быстрый запуск на Windows

1. Установите **Node.js 22.12 или новее** с https://nodejs.org/ (npm входит в установку).
2. Распакуйте весь ZIP, например в `C:\Projects\vodopyanov-site`. Не запускайте файлы прямо из архива.
3. Откройте `START-WINDOWS.bat` двойным щелчком.
4. При первом запуске установятся зависимости. Нужен интернет.
5. Браузер откроет http://127.0.0.1:5173. Оставьте окно запуска открытым.

Для остановки нажмите **Ctrl+C** в окне запуска. Для повторного запуска откройте BAT-файл снова.
Если браузер не открылся автоматически, перейдите по адресу вручную.

## Запуск через терминал

Откройте терминал в папке проекта:

```bash
npm ci
npm run dev -- --host 127.0.0.1 --open
```

Если PowerShell блокирует npm.ps1, используйте `npm.cmd ci` и `npm.cmd run dev` или BAT-файл. Менять политики Windows не требуется.

## Сборка и проверка готового сайта

```bash
npm run build
npm run preview -- --host 127.0.0.1 --open
```

Результат сборки — папка `dist/`. Preview обычно доступен на http://127.0.0.1:4173; точный адрес выводится в терминале.
Для своего сервера загрузите содержимое `dist/` в корень домена.

## Где менять содержимое

- `src/data/content.ts` — имя, описание, стихи, звуковые эскизы и три контакта.
- `src/App.vue` — главы, занавес, навигация и аудиоинтерфейс.
- `src/components/CinematicStage.vue` — микрофон, камера, свет и 3D-сцена.
- `src/style.css` — оформление и адаптация.
- `public/images/portrait.webp` — портрет автора.
- `public/models/microphone.glb` — модель; источник и лицензия в `public/models/CREDITS.txt`.

В массиве `contacts` заполните `href`: Telegram — `https://t.me/ВАШ_ЛОГИН`, ВКонтакте — URL страницы, Email — `mailto:ВАША_ПОЧТА`.
Пустые значения отображаются как «Адрес скоро появится».

Стихи — демонстрационные тексты, не произведения автора. Аудио — синтезированные эскизы без вокала. Для настоящих песен подключите аудиофайлы вместо функции синтеза.

Не открывайте index.html двойным щелчком: используйте Vite.
Для 3D нужен WebGL и аппаратное ускорение браузера. При недоступности WebGL остаётся упрощённая сцена.
Если в системе включено уменьшение движения, занавес и анимация камеры пропускаются.
Шрифты загружаются из Google Fonts; без интернета используются системные. Изображения и модель локальные.

Сборка проверена в Linux. BAT-файл на Windows и визуальный результат на вашем ПК не проверялись.
